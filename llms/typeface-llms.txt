## API Reference
- [Get access token](https://developers.typeface.ai/reference/post_oauth2-token.md): This API endpoint allows authorized client applications to obtain an access token using their Application credentials. The access token is required to authenticate and authorize requests to other Typeface AI API endpoints.   **Token Expiration & Renewal**:  Access tokens are valid for one hour.  To maintain uninterrupted access to Typeface AI APIs, client applications should implement a mechanism to:   - *Periodically Refresh*: Automatically fetch a new access token before   the current one expires.   - *Error-Based Refresh*: Fetch a new access token when encountering a 401   Unauthorized error, indicating token expiration.
- [Discovery API](https://developers.typeface.ai/reference/discoveridentity.md): Retrieve all teams the app has access to.  If the app has access to some specific teams, the links for operating on these teams can be found under each team. Otherwise, if the app has access has access to entire Org, use the Query teams API.

Filter by tags Use the `tags` array to filter assets by one or more tag names. Tag filtering is hierarchical. When you filter by a parent tag, assets tagged with any of its descendants are automatically included. - [Get Generated Content](https://developers.typeface.ai/reference/getreadonlydocument.md): Retrieve generated content using this API. Response contains array of blocks and each block corresponds to a content fragment. For simple text and image, there will be only one block. Each block has `type` which indicates the content type and `variations` generated.
- [Create Tags](https://developers.typeface.ai/reference/createtags.md): Creates one or more tags in a single request. Each tag in the request is processed independently, so some tags may succeed while others fail. The response contains a per-item result for every tag in the request, each marked with `success: true` or `success: false`.  For each tag, provide a `name` and `displayName`. Optionally include `parentId` to nest the tag under an existing parent, and `properties` to attach metadata such as `description`. Tags without a `parentId` are created as top-level tags.  The top-level `success` field in the response is `true` only when every tag was created successfully. If any tag fails, `success` is `false` (partial success).
- [Get Tag by ID](https://developers.typeface.ai/reference/gettag.md): Retrieves the full definition of a single tag by its ID. The response includes the tag's name, display name, status, parent reference, and description.
- [Patch Tag](https://developers.typeface.ai/reference/patchtag.md): Partially updates an existing tag using JSON Patch-style operations. Supported paths are `/name`, `/displayName`, `/status`, and `/description`.  Common use cases include renaming a tag, deactivating it, updating its description, or approving / rejecting a pending tag candidate (set status to `ACTIVE` to approve, `REJECTED` to reject).
- [Delete Tag](https://developers.typeface.ai/reference/deletetag.md): Permanently deletes a tag and all of its child tags. Any assets that were tagged with the deleted tag will have that tag association removed.
- [Search Tags](https://developers.typeface.ai/reference/searchtags.md): Search for tags within an account. Use this to browse the tag taxonomy, find tags by name, or list tags filtered by status.  - **`query`** — Filters tags by name or display name. Searching for a parent tag also returns all of its descendants. When omitted or empty, all tags are returned. - **`status`** — Filters tags by status (`ACTIVE`, `INACTIVE`, `DEPRECATED`, `REJECTED`, `PENDING`). Defaults to `ACTIVE`. Set to `PENDING` to list newly discovered tag candidates awaiting review. - **`limit`** / **`cursor`** — Use cursor-based pagination for large result sets.
